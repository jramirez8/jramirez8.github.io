# Juan Ignacio Ramirez — Professional Site

Static personal website built for GitHub Pages. No build step, no dependencies.

## Publish on GitHub Pages

1. Create a repository named `<your-github-username>.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Your site will be available at `https://<your-github-username>.github.io/`.

## Files

- `index.html` — site content
- `styles.css` — responsive styling
- `script.js` — current year only
- `assets/juan-ramirez.jpg` — profile photo
- `assets/Juan_Ramirez_Shipboard_IT_CV.pdf` — downloadable resume
- `.nojekyll` — tells GitHub Pages to publish files as-is

## Before publishing

Review dates, names and claims. If you want a custom domain later, configure it under **Settings → Pages → Custom domain**.
